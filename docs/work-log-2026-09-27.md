### Tóm tắt thực hiện
Triển khai hoàn chỉnh tính năng đăng nhập/đăng ký bằng Google (Android + Web GIS) và cơ chế tự động làm mới phiên (refresh token rotation) dùng chung cho toàn bộ app theo hợp đồng Backend và Spec Kit:
- **Dependency & SDK**:
  - Bổ sung `google_sign_in: ^7.2.0` và `google_sign_in_web: ^1.1.3` vào `pubspec.yaml`.
  - Khởi tạo `GoogleSignIn.instance.initialize()` với `clientId` (Web) và `serverClientId` (Android) lấy động theo môi trường API host qua ENV/`--dart-define`.
- **UI/UX Quiet Luxury (`.agents/skills`)**:
  - Tạo `GoogleLogo` widget bằng `CustomPainter` vector sắc nét 4 màu chuẩn Google (Red `#EA4335`, Yellow `#FBBC05`, Green `#34A853`, Blue `#4285F4`), không phụ thuộc ảnh mạng/asset thiếu.
  - Widget `GoogleSignInButton`:
    - Android/Mobile: Nút tự vẽ phong cách Quiet Luxury, surface white `#FFFFFF`, border tinh tế `#E5E2DE`, font chữ Be Vietnam Pro (`#1A1A1A`), chiều cao 50dp (touch target >= 48dp).
    - Web: Tự động phát hiện và render `GoogleSignInPlugin().renderButton()` theo chuẩn Google Identity Services (GIS).
    - Loading & Debounce (FR-012): Hiển thị spinner và disable nút khi đang xử lý để chống bấm lặp.
    - Xử lý huỷ (FR-008): Người dùng đóng/huỷ chọn tài khoản Google không hiển thị lỗi nghiêm trọng.
  - Tích hợp vào cả `LoginScreen` và `RegisterScreen` kèm đường phân cách Quiet Luxury ("HOẶC").
  - Auto-link tài khoản cũ (FR-006): Hiển thị thông báo nhẹ (SnackBar) khi email Google trùng với tài khoản Closy đã có và tự động liên kết thành công.
- **Mô hình phiên & Refresh Rotation (FR-009, US3)**:
  - Cài đặt interceptor 401 **single-flight** trong `ApiClient`: khi nhiều request gặp 401 cùng lúc, chỉ phát đúng 1 request làm mới token tới `POST /auth/refresh-token` với `{oldRefreshToken, deviceName}`.
  - Sau khi refresh thành công: lưu cặp token mới (access/refresh) vào `flutter_secure_storage` và retry request gốc 1 lần.
  - Nếu refresh thất bại: phát tín hiệu forced-logout an toàn tới `AuthNotifier` -> xoá sạch token, đặt lại trạng thái và đưa người dùng về `/login`.
  - Hỗ trợ `logout()` chuẩn: gửi `{refreshToken}` trong body tới `POST /auth/logout` kèm Bearer header, xoá storage và bump `sessionProvider`.
  - Tự động khôi phục phiên (SC-005, QS-007): Kiểm tra token hợp lệ khi khởi động app mà không bắt đăng nhập lại.

## 5. Bug Fix: Hiển thị Google Sign-In trên Web / Edge

### Nguyên nhân nút Google không hiển thị trên Web (`flutter run -d edge/chrome --web-port 8081`):
1. **Thiếu meta tag Client ID trong `web/index.html`**:
   Google Identity Services (GIS) trên Web yêu cầu thẻ `<meta name="google-signin-client_id" content="...">` trong `<head>` để tự động phát hiện Client ID khi trang web load. Thiếu thẻ này khiến GIS không thể khởi tạo tự động.
2. **Khởi tạo sai instance trong `web_button_web.dart`**:
   Code trước đó gọi `GoogleSignInPlugin().renderButton()` tạo một instance mới toanh chưa được gọi `init()`, dẫn tới `_initialized` Completer không bao giờ hoàn thành và FutureBuilder bị kẹt vĩnh viễn ở trạng thái `Text('Getting ready')`.
3. **Khai báo conditional export `dart.library.js_interop`**:
   Bổ sung thêm `if (dart.library.html)` và `if (dart.library.js)` trong `web_button.dart` để tương thích hoàn toàn các runtime web Flutter.
4. **Thiếu kích thước ràng buộc (Container/SizedBox)**:
   `renderButton()` trả về `FlexHtmlElementView` có initial size là 1x1 pixel. Nếu chưa hoàn thành resize observer hoặc không có `SizedBox` bọc ngoài, nó sẽ bị thu nhỏ thành 0 hoặc 1px.
5. **Tiền khởi tạo SDK trong `main.dart`**:
   Khởi tạo `GoogleSignIn.instance.initialize()` ngay trong `main()` sau khi load `.env` để khi màn hình `LoginScreen` render, GIS đã sẵn sàng tức thì không có độ trễ hay nhấp nháy "Getting ready".

### Các file đã cập nhật khắc phục:
- `web/index.html`: Đã thêm `<meta name="google-signin-client_id" content="...">`.
- `lib/features/auth/presentation/widgets/web_button_web.dart`: Dùng `GoogleSignInPlatform.instance` singleton + `GSIButtonConfiguration(size: large, shape: pill, theme: outline, minimumWidth: 280)` + Fallback Quiet Luxury.
- `lib/features/auth/presentation/widgets/web_button.dart`: Đầy đủ conditional export.
- `lib/features/auth/presentation/widgets/google_sign_in_button.dart`: Bọc `SizedBox(height: 48)` cho web button + quản lý loading spinner + trigger `setState` sau khi SDK khởi tạo.
- `lib/main.dart`: Tiền khởi tạo `GoogleSignIn.instance.initialize()` an toàn trong `main()`.
- `pubspec.yaml`: Thêm `google_sign_in_platform_interface: ^3.1.0`.
- Kiểm tra lại: `flutter analyze` 0 issues, 19/19 test passed.

## 7. Fix `400: origin_mismatch` — chuyển Google login web sang luồng redirect của BE (2026-09-27)

### Nguyên nhân
- GIS kiểm tra **origin trang web** với "Authorized JavaScript origins" của OAuth client; origin dev (`http://localhost:8081`) chưa đăng ký → `400: origin_mismatch`. Với GIS thì không thể sửa bằng code.

### Cách sửa (code — không cần đụng Google Console)
- Chuyển **web** sang **luồng redirect do BE điều khiển (guide §1)**:
  - `lib/features/auth/presentation/widgets/web_button_web.dart`: nút web điều hướng `GET {API_BASE}/auth/google?redirectUrl=<origin>/auth/callback` (dùng `package:web`).
  - `lib/core/constants/app_constants.dart`: thêm `googleWebRedirectUrl(returnUrl)`.
  - `lib/features/auth/presentation/auth_callback_screen.dart` (mới) + route `/auth/callback` (miễn redirect guard) — đọc `?error=` và xác nhận phiên.
  - `lib/features/auth/data/auth_repository.dart`: `completeWebSession()` (gọi `/me` kèm cookie → lưu placeholder `web_session_active`); `isAuthenticated()` chấp nhận placeholder.
  - `lib/features/auth/providers/auth_provider.dart`: `completeWebGoogleLogin()`.
  - `lib/features/auth/presentation/widgets/google_sign_in_button.dart`: web dùng nút redirect, bỏ GIS listener; `lib/main.dart`: chỉ init SDK trên Android/iOS.
  - `pubspec.yaml`: thêm `web`; `web/index.html`: bỏ `<meta google-signin-client_id>` hardcode.
- Android giữ nguyên: ID token → `POST /auth/google` → Bearer.

- Điều kiện BE: `FRONT_END_ORIGIN` có `http://localhost:8081` (đã có sẵn).
- **Path URL strategy**: Flutter web mặc định dùng hash (`/#/...`) nên redirect về `/auth/callback` (path) sẽ không vào đúng route. Đã bật `usePathUrlStrategy()` qua conditional import (`lib/core/router/url_strategy{,_web,_stub}.dart`) và thêm `flutter_web_plugins` vào `pubspec.yaml`. `vercel.json` đã có SPA rewrite `/(.*) → /index.html` nên production OK.
