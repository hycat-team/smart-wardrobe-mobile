## Fix crash "Tried to modify a provider while the widget tree was building" khi điều hướng (nhất là sau khi thêm quần áo / reload web)

### Vấn đề
- Màn hình đỏ (Flutter error overlay) với nội dung `At least listener of the StateNotifier Instance of 'StateController<String?>' threw... Tried to modify a provider while the widget tree was building`.
- Stack trỏ `lib/core/router/app_router.dart:88:42`: `redirect` của go_router ghi trực tiếp `pendingRedirectProvider.notifier).state = ...`.
- Trên web, go_router `restoreState`/`parseRouteInformationWithDependencies` chạy redirect **trong lúc build**; khi URL là route bảo vệ mà `isAuthenticated` còn `false` (cold start/hot restart/reload trước khi `checkAuthStatus` xong) → nhánh 1 ghi provider → Riverpod throw.

### Thay đổi
- `lib/core/router/app_router.dart`: đọc `pendingRedirectProvider` bằng `ref.read(pendingRedirectProvider)` và **hoãn mọi ghi provider trong `redirect` sang `Future.microtask`** (cả set destination lẫn clear pending). Không ghi provider đồng bộ trong callback build.

### Verify
- `flutter analyze`: 0 issues.
- `flutter test` (15 unit/widget): pass.
- Ghi chú: các chỗ ghi provider còn lại (`login_screen`, `home_screen`, notifier) đều nằm trong event handler, không phải build.
